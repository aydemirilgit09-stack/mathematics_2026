
# Problem 6: Parameter and Invertibility
## Question
### Given

A(t) = [[t, 1], [2, t]]
## Solution
### 1. Calculate the Determinant

det(A) = (t * t) - (1 * 2)

det(A) = t^2 - 2

### 2. Determine When the Matrix Is Not Invertible

A matrix is not invertible when its determinant is zero.

t^2 - 2 = 0

t^2 = 2

t = ±√2

### 3. Explanation

The matrix is not invertible when t = √2 or t = -√2.

For all other values of t, the determinant is not zero, so the matrix is invertible.

### Final Result

t = ±√2

The matrix is not invertible when its determinant equals zero.
