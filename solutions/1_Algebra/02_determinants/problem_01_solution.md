
# Problem 1: Determinant of a 2x2 Matrix

## Given

A = [[3, -2], [5, 4]]

B = [[1, 7], [2, 14]]

## 1. Calculate det(A)

det(A) = (3 * 4) - (-2 * 5)

det(A) = 12 + 10

det(A) = 22

## 2. Calculate det(B)

det(B) = (1 * 14) - (7 * 2)

det(B) = 14 - 14

det(B) = 0

## 3. Determine Invertibility

Matrix A is invertible because its determinant is not zero.

Matrix B is not invertible because its determinant is zero.

## Final Results

det(A) = 22

det(B) = 0

Matrix A is invertible, while matrix B is singular.
