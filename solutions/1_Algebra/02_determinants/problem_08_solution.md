
# Problem 8: Determinant of a Product
## Question
### Given

det(A) = 3

det(B) = -5
## Solution
### 1. Calculate det(AB)

Using the determinant product property:

det(AB) = det(A) * det(B)

det(AB) = 3 * (-5)

det(AB) = -15

### 2. Calculate det(BA)

det(BA) = det(B) * det(A)

det(BA) = (-5) * 3

det(BA) = -15

### 3. Calculate det(A^-1 B)

The determinant of an inverse matrix is:

det(A^-1) = 1 / det(A)

det(A^-1 B) = det(A^-1) * det(B)

det(A^-1 B) = (1/3) * (-5)

det(A^-1 B) = -5/3

### 4. Explanation

Although matrix multiplication is generally not commutative, the determinants of AB and BA are equal.

This is because multiplication of real numbers is commutative.

### Final Results

det(AB) = -15

det(BA) = -15

det(A^-1 B) = -5/3
