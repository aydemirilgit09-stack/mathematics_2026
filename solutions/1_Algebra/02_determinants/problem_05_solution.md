## Given

A = [[1, 2, 3], [2, 1, 0], [-1, 4, 2]]

## 1. Apply Row Operations

R2 = R2 - 2R1
R3 = R3 + R1

The matrix becomes:

[[1, 2, 3], [0, -3, -6], [0, 6, 5]]

## 2. Calculate the Determinant

det(A) = 1 * ((-3 * 5) - (-6 * 6))

det(A) = -15 + 36
