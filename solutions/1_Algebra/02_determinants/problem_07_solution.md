
# Problem 7: Using Properties Instead of Recomputing
## Question
### Given

det(A) = -4

A is a 3x3 matrix.
## Solution
### 1. Calculate det(2A)

For an n x n matrix:

det(kA) = k^n * det(A)

det(2A) = 2^3 * (-4)

det(2A) = 8 * (-4) = -32

### 2. Calculate det(A^T)

The determinant of a transpose equals the determinant of the original matrix.

det(A^T) = det(A) = -4

### 3. Calculate det(A^2)

det(A^2) = det(A) * det(A)

det(A^2) = (-4) * (-4) = 16

### 4. Calculate det(-A)

det(-A) = (-1)^3 * det(A)

det(-A) = -1 * (-4) = 4

### Final Results

det(2A) = -32

det(A^T) = -4

det(A^2) = 16

det(-A) = 4
